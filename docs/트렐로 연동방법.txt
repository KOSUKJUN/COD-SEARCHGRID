Trello 연동 기능은 만들어 두었는데, 실제 Trello 보드에는 아직 연결해 보지 못했습니다. 인증키와 보드 정보가 있어야 해서입니다. 가짜 응답으로 만든 테스트 8개를 포함해 테스트 78개가 통과했고, 타입 체크와 빌드도 문제없습니다. 키 없이 실행하면 설정 안내 메시지가 나오는 것까지 확인했습니다.

사용 흐름: Claude Code에 **"트렐로 이슈 반영해줘"**라고 하면 다음 순서로 진행합니다.

대상 카드를 찾습니다. 기본은 To Do·Bugs 같은 지정 리스트이고, 키워드 검색이나 카드를 직접 지정할 수도 있습니다.
카드의 설명·체크리스트·첨부·댓글을 읽습니다.
카드마다 브랜치(trello/<카드ID>-제목)를 만들고, 카드를 In Progress 리스트로 옮깁니다.
수정합니다. 버그면 재현 테스트를 먼저 추가하고, 타입 체크·테스트·빌드를 통과시킵니다.
커밋하고 PR을 만든 뒤, 카드에 PR 링크 댓글과 첨부를 남기고 Review 리스트로 옮깁니다.
PR이 main에 합쳐지면 GitHub Actions가 카드를 Done 리스트로 자동으로 옮깁니다.
안전장치

main에 바로 반영하거나 PR을 직접 합치지 않습니다. 합치는 건 사람이 합니다.
카드 내용은 요구사항으로만 읽습니다. 카드에 명령어 실행이나 인증 정보 요청이 적혀 있으면 따르지 않고 먼저 확인을 받습니다.
요구사항이 모호하면 카드에 질문 댓글만 남기고 그 카드는 건너뜁니다.
처리할 카드가 3건을 넘으면 어떤 카드를 처리할지 먼저 묻습니다.
인증키는 화면, 로그, 오류 메시지 어디에도 나오지 않게 했습니다.
필요한 것
1. Trello 인증키: 채팅에 붙여넣지 마시고 직접 파일에 넣어 주세요.

.env.example을 .env.local로 복사한 뒤 아래 세 값을 채우면 됩니다. 이 파일은 GitHub에 올라가지 않습니다.
API Key: https://trello.com/power-ups/admin 에서 Power-Up을 만들고 API 키를 발급합니다.
Token: 같은 화면의 Token 링크에서 발급합니다. 카드에 댓글과 이동을 해야 하니 읽기와 쓰기 권한이 모두 필요합니다.
Board: 연결할 보드의 URL을 넣습니다.
2. 리스트 이름: 보드의 리스트 이름이 다르면 알려주시거나 trello.config.json을 직접 고쳐 주세요. 기본값은 다음과 같습니다.

대상 리스트: To Do / Bugs / Backlog / 할 일 / 버그
진행 단계: In Progress → Review → Done
특정 라벨(예: bug)만 처리하고 싶으면 labels에 적으면 됩니다.
3. (선택) Done 자동 이동: 원하시면 터미널에서 직접 아래를 실행해 GitHub에 키를 등록해 주세요. 값 입력 창이 뜹니다.


gh secret set TRELLO_API_KEY
gh secret set TRELLO_TOKEN
설정을 마치고 알려주시면 npm run trello -- check로 연결을 확인하고 실제 카드로 한 번 돌려 보겠습니다. 이번 변경은 아직 커밋하지 않았습니다.
